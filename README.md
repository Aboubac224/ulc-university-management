# ULC university management

ULC University Management is an evolving university management platform designed for students, faculty members, administrative staff, university departments, and support services.

## 🎯 Objective

The objective of this project is to gradually build a professional full-stack web application that includes:

- A public home page
- An authentication system
- User management
- Course management
- Department management
- Program management
- University service management

## 🛠️ Technologies

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend — Planned

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL

## 🚧 Project Status

Version 1 — In progress: Creating the public home page.
